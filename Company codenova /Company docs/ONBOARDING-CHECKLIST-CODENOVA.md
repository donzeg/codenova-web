# Onboarding Checklist — CodeNova Innovations Ltd.

**Effective Date:** 28 February 2026  
**Prepared By:** HR Manager (Safiya Aminu)  
**For New Hires:** All Staff  

---

## Pre-Start Phase (Before Start Date)

### [ ] HR & Documentation
- [ ] Receive signed offer letter acceptance from candidate
- [ ] Collect required documents:
  - Valid government-issued ID (passport, driver's license, national ID)
  - Educational certificates (transcripts, diplomas, professional certifications)
  - Bank account details (account number, bank name, account holder name)
  - Next of kin information (name, relationship, phone number)
  - Tax Identification Number (TIN) — or guide for registration
  - National Identification Number (NIN) for PAYE processing
- [ ] Create employee file (personnel record)
- [ ] Register employee with nominated Pension Fund Administrator (PFA)
  - Collect RSA PIN confirmation (to be provided within 14 days of start date)
- [ ] Register employee with FIRS for PAYE (if TIN not yet obtained)
- [ ] Update TEAM-MEMBERS.md with new hire information

### [ ] IT & System Access
- [ ] Create company email account (format: firstname.lastname@codenova.cc)
- [ ] Set up network/VPN access credentials
- [ ] Assign company laptop/device (if applicable)
- [ ] Create accounts for collaboration tools (Slack, Drive, shared systems)
- [ ] Set up time tracking system access
- [ ] Assign office access card & security code (if applicable)

### [ ] Office & Workspace
- [ ] Prepare physical workspace (desk, chair, supplies)
- [ ] Reserve parking space (if applicable)
- [ ] Prepare welcome package (company handbook, facilities guide, tea/coffee supplies)
- [ ] Ensure office is clean and organized for arrival

### [ ] Direct Manager Preparation
- [ ] CEO assigns reporting manager and communicates reporting line
- [ ] Manager prepares:
  - Detailed role onboarding plan (7-day and 30-day initiatives)
  - Organizational charts and team contact list
  - Role-specific resources and templates
  - Initial project/task assignments

## **Day 1 — Welcome & Orientation**

### [ ] HR & Administration (08:30–09:30)
- [ ] Welcome meeting with HR Manager (Safiya Aminu)
  - Confirm employment terms
  - Explain payroll processing (monthly schedule, penalties for non-compliance)
  - Review statutory deductions: PAYE, pension (8%), NHIS
  - Discuss leave policy (20 days annual, leave request process)
  - Provide employee handbook
  - Explain grievance and disciplinary procedures

### [ ] IT Setup (09:30–10:30)
- [ ] IT Support: Set up email, Slack, file system access
- [ ] Confirm device (laptop, phone) is configured
- [ ] Test network connectivity and VPN (if remote work required)
- [ ] Provide password manager setup guide
- [ ] Collect device agreement signature

### [ ] Company Overview (10:30–11:30)
- [ ] CEO or Operations Lead provides company briefing:
  - Company vision, mission, and strategic objectives
  - Current projects and deliverables
  - Client portfolio (if applicable)
  - Organizational structure and reporting lines
  - Key performance metrics

### [ ] Office Tour & Facilities (11:30–12:00)
- [ ] Tour of office layout:
  - Restrooms, kitchenette, break room
  - Emergency exits and assembly point
  - Parking and security procedures
  - Facilities manager contact (for maintenance issues)

### [ ] Team Introductions (12:00–13:00)
- [ ] Lunch with immediate team members
- [ ] Meet all staff:
  - CEO (Sadiq Yusuf)
  - HR Manager (Safiya Aminu)
  - Operations Lead (Hassan Bwala)
  - Admin Officer (Abdulhameed Yusuf)
- [ ] Assign "buddy" (peer mentor for first week)

### [ ] Payroll & Documents (13:00–14:00)
- [ ] HR Manager confirms:
  - Bank account details recorded (for salary payment)
  - Pension enrollment documents signed
  - Tax relief certificate (Form IT1) completed and filed
  - First salary payment date (typically end of first month)
- [ ] Employee confirms RSA PIN will be provided within 14 days

## **First Week — Role Onboarding**

### [ ] Daily Standups
- [ ] Attend daily team meeting (09:00 AM, 30 minutes)
- [ ] Discuss progress, blockers, and support needed
- [ ] Meet with direct manager daily to check in

### [ ] Role Training (Customized per Position)

**For CEO/Leadership Roles:**
- [ ] Review financial reports and company accounts
- [ ] Meet with external stakeholders (clients, vendors, regulatory bodies)
- [ ] Review strategic documents and board-level responsibilities

**For HR Manager:**
- [ ] Review current personnel files and employment records
- [ ] Learn payroll system and PAYE filing process
- [ ] Familiarize with compliance calendar (statutory deadlines)
- [ ] Review recruitment processes and pipeline

**For Operations Lead:**
- [ ] Review current projects and timelines
- [ ] Meet with field staff and client contacts
- [ ] Learn operational workflows and KPI reporting
- [ ] Review resource allocation and budget tracking

**For Admin Officer:**
- [ ] Learn office procedures and vendor contacts
- [ ] Set up document management system access
- [ ] Review company filing system and record keeping
- [ ] Learn procurement and expense tracking processes

### [ ] Documentation & Acknowledgments
- [ ] Employee signs:
  - Employment contract (2 copies; keep 1, return 1)
  - Confidentiality & IP agreement
  - Code of conduct & ethics policy
  - Safety and security protocols
- [ ] HR collects and files signed documents

### [ ] System & Software Training
- [ ] Run through company-specific software/tools:
  - Time tracking system
  - HR system (leave application, payroll view)
  - Project management tools
  - Financial/accounting systems (if applicable)
  - Communication protocols (email, Slack, meetings)

### [ ] Goal Setting (End of Week 1)
- [ ] Manager and employee define:
  - **30-Day Goals:** Specific, measurable targets for first month
  - **Probation Review Criteria:** Key performance indicators for 3-month review
  - **Learning Agenda:** Skills to develop during probation
  - **Schedule regular 1-on-1s:** Weekly during probation (30 minutes minimum)

## **First Month — Integration & Competency**

### [ ] Week 2–4 Focus
- [ ] Complete all assigned training modules
- [ ] Deliver initial assignments/projects
- [ ] Attend all relevant team meetings and client interactions
- [ ] Build relationships with team and stakeholders
- [ ] Identify any support needs or barriers to productivity

### [ ] Weekly 1-on-1 Meetings
- [ ] Manager reviews progress against 30-day goals
- [ ] Address any challenges or unclear expectations
- [ ] Provide constructive feedback
- [ ] Adjust onboarding plan if needed

### [ ] Mid-Month Check-in (Day 15)
- [ ] HR & Manager: Informal progress review
  - Is employee settling in well?
  - Any HR or compliance issues?
  - Performance on main responsibilities?
- [ ] Adjust support or training as needed

### [ ] Month-End Payroll
- [ ] First salary payment (following company schedule)
- [ ] Confirm pension deduction on payslip
- [ ] Verify net amount matches offer letter expectations
- [ ] HR confirms PAYE filing completed with FIRS

## **Probation Period — 3-Month Assessment**

### [ ] Probation Review (Day 85–90)
- [ ] Formal meeting with:
  - HR Manager (Safiya Aminu)
  - Direct Manager
  - CEO (if critical role) OR Operations Lead (for staff roles)

### [ ] Review Criteria
- **Performance:** Achievement of 30-day and probation goals
- **Conduct:** Adherence to company policies and code of conduct
- **Competency:** Ability to perform core job responsibilities
- **Fit:** Cultural alignment and team integration
- **Probation Terms:** Understanding of employment contract and policies

### [ ] Possible Outcomes
1. **Confirmation of Employment** — Issued in writing; benefits/entitlements now apply
2. **Extension of Probation** — Additional 1–3 months with specific improvement targets
3. **Termination During Probation** — Per employment contract (1 week notice)

### [ ] Post-Probation Actions
- [ ] If confirmed:
  - Issue confirmation letter
  - Update employment record
  - Discuss career development and long-term goals
  - Begin annual performance review cycle
- [ ] If extended:
  - Define specific, measurable targets for extension period
  - Schedule check-in meetings (bi-weekly minimum)
  - Document support provided
- [ ] If terminated:
  - Final settlement calculations (pro-rata leave, pension, etc.)
  - Exit interview with HR
  - Return all company property
  - Confirm confidentiality agreements remain binding

---

## **Post-Probation — Ongoing Integration**

### [ ] First Quarter (Months 4–6)
- [ ] Continue monthly 1-on-1s with manager
- [ ] Participate in company events and training
- [ ] Begin preparing for annual performance review (Month 6)
- [ ] Discuss development opportunities and career path

### [ ] Annual Cycles
- **Performance Reviews:** Conducted annually in January/December
- **Leave Management:** Annual leave accrual tracked (20 days/year)
- **Salary Review:** Conducted annually; adjustments effective January
- **Training & Development:** Identify skill gaps and training needs
